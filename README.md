# 日常 Daily — 個人生活管理 PWA（第二版）

## 第二版更新
- 待辦事項：新增起始日期與時間、到期日期、優先程度顏色；既有待辦可編輯。
- 習慣追蹤：每個習慣可設定目標分鐘數、起始日期與時間、每日提醒時間。
- 每日進度：可用滑桿調整各習慣的 0–100% 進度，時間型習慣會換算已完成分鐘數。
- 習慣行事曆：按月瀏覽、選擇過往日期並查看／調整該日進度。
- 延續 IndexedDB 本機儲存、JSON 匯入／匯出、Service Worker 離線快取。
- 既有習慣資料會沿用；名稱含「20 分鐘」等數字的舊習慣會嘗試自動帶入目標分鐘數。

## 提醒限制
習慣提醒只會在 App／網頁開啟且 JavaScript 正在執行時檢查；App 關閉、手機鎖定或系統暫停背景執行時，不保證準時提醒。允許通知後，瀏覽器可能顯示通知；iPhone 上的網頁通知支援會依 iOS 版本、是否加入主畫面及權限而異。這不是可靠鬧鐘，也沒有伺服器推播。

## 資料安全
- 所有資料存在目前瀏覽器／裝置的 IndexedDB，不會自動同步到其他裝置。
- 更新前先在目前 iPhone App 匯出 JSON 備份，請勿把備份上傳到公開 GitHub。
- 本版延續原有資料庫，不會刻意清除舊資料；仍建議先備份，再更新。
- 匯入備份會取代目前資料，請先匯出現有資料。

## 部署
將 `index.html`、`manifest.webmanifest`、`sw.js`、`icon.svg`、`README.md` 放在 GitHub Pages repository 根目錄。提交新版後，等待 Pages 部署完成，再重新開啟 iPhone 上的 PWA。若仍看到舊版，關閉 App 後重新開啟或重新載入網站。

## 本機測試
使用 VS Code Live Server 開啟 `index.html`，或在資料夾中執行 `python -m http.server 8000`，再開啟 `http://localhost:8000`。
