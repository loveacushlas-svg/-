# 日常 Daily v3

## 更新方式
1. 先在舊版 App 的「更多」匯出 JSON 備份，妥善保存。
2. 將本資料夾中的 index.html、manifest.webmanifest、sw.js、icon.svg、README.md 上傳到原 GitHub Pages 儲存庫根目錄，覆蓋同名檔案。
3. 等待 GitHub Pages 部署，重新啟動 iPhone 主畫面上的 App。若仍顯示舊版，關閉 App 再開啟或以 Safari 重新造訪。
4. 確認既有資料後測試習慣、日誌、旅遊、汽車及報表。

## 注意
- IndexedDB 本機儲存，GitHub Pages 更新不會主動清除資料，但清除 Safari 網站資料、變更網址、無痕模式等仍可能造成資料遺失。
- 已移除習慣改為封存，歷史打卡仍保留於完成明細。
- 每月任意天數可輸入每月指定日期（例如 1,8,15）；若未填則依每月前 N 天排程。每週任意天數可勾選星期。
- 單次／日／週／年為目標週期的分類；目前進度仍以每日打卡為單位，不會自動跨週或跨年累加。
- 習慣與汽車提醒僅在 App 開啟、JavaScript 執行時檢查；關閉 App 或 iOS 暫停背景執行時無法保證通知。
- 下次保養里程會記錄並顯示，但因無法取得即時里程，尚無里程自動提醒。
- 報表中的日期可查看當天各類別筆數，分類明細支援待辦、習慣、日誌、汽車編輯；旅遊可跳轉清單。
